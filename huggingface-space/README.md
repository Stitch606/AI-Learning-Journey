# Human Action Detection

A minimal Gradio Space containing a video display area and two interface buttons.

## Project files

- `app.py`: Gradio application and custom CSS.
- `gpu.py`: Hugging Face ZeroGPU helper and startup GPU registration.
- `requirements.txt`: Additional Python dependencies.

## Run locally

```bash
pip install -r requirements.txt
python app.py
```

Gradio is provided by the Hugging Face Space SDK version declared in this README.
