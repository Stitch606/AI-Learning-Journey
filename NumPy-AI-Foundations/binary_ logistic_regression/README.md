Customer Churn Prediction

📌 Project Idea

This is a simple machine learning project that predicts whether a customer will stay or leave a service.


---

🎯 What the Model Does

The model takes customer information such as age, income, activity, and device type, then predicts:

0 → Customer stays

1 → Customer leaves



---

🧠 Model Type

Logistic Regression (Binary Classification)



---

⚙️ Project Goal

Learn the basics of Machine Learning

Train a simple model on customer data

Understand customer churn prediction



---

🛠️ Tools Used

Python

NumPy

Pandas
